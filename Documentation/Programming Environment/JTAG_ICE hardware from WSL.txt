#########################################################################################################
Create udev rule in WSL terminal:

gerald@MSI-DESKTOP:~$ sudo vim /etc/udev/rules.d/99-avr-jtag.rules
# Atmel-ICE (EDBG)
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2141", MODE="0666", GROUP="plugdev"

# AVR Dragon
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2107", MODE="0666", GROUP="plugdev"

# JTAGICE mkII
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2103", MODE="0666", GROUP="plugdev"

# JTAGICE 3
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2140", MODE="0666", GROUP="plugdev"

save and exit

apply rules in WSL terminal:
gerald@MSI-DESKTOP:~$ sudo udevadm control --reload-rules && sudo udevadm trigger
gerald@MSI-DESKTOP:~$ sudo usermod -aG plugdev $USER

verify rules WSL terminal:

#########################################################################################################

Set mcu fuses:
Note: you can use avrdude/AVRDUDESS while you have the Atmel-Ice setup with usbipd.
You CANNOT with Microchip studio.

With AVRDUDESS:
open bit fuses; select OCDEN and JTAGEN to 0, HFUSE should now have 0x18, click write fuses.
To reverse, select OCDEN and JTAGEN to 1, HFUSE should now have 0xD8, click write fuses.

With avrdude cli:
avrdude.exe -c atmelice_isp -p m32u4 -F -v -v -U lfuse:w:0xFF:m -U hfuse:w:0x18:m -U efuse:w:0xFB:m
to reverse: avrdude.exe -c atmelice_isp -p m32u4 -F -v -v -U lfuse:w:0xFF:m -U hfuse:w:0xD8:m -U efuse:w:0xFB:m

With Microchip Studio Device Programming Dialog:
First you have to detach and unbind the Atmel-Ice with usbipd
Open device programming dialog
Tool: Atmel-Ice, Device: ATmega32u4 (for example), Interface: JTAG or ISP (depends on which you have hooked up and/or prefer). 
click device signature read, click target voltage read.
Select HIGH.OCDEN, select HIGH.JTAGEN, click Program.
To reverse, unselect HIGH.OCDEN, select HIGH.JTAGEN, click Program.
