MYSYS MINGW AVaRICE compilation

1) Download MYSYS2
https://www.msys2.org/

2) install MYSYS2

3) Launch MYSYS2 MYSYS shell from Start menu

4)in MYSYS2 MYSYS shell, update package database and core system packages
    Gerald@MSI-DESKTOP MYSYS ~
    $ pacman -Syu
a) the shell will close, reopen and run full system upgrade to complete
    Gerald@MSI-DESKTOP MYSYS ~
    $ pacman -Su

5) navigate to https://github.com/avrdudes/avarice/actions/runs/20374190577/job/58548209153
a) expand Run mysys2/setup-mysys2@v2 > Installing additional packages through pacman...
b) in MYSYS2 MYSYS shell, install libraries
    Gerald@MSI-DESKTOP MYSYS ~
    $ pacman --noconfirm -S --needed --overwrite * git make unzip gcc libtool msys/autotools msys/autoconf-wrapper automake cmake msys/binutils mingw-w64-x86_64-libusb
  
6) Build libusb
a) in browser, expand Build libusb > Run git clone https://github.com/libusb/libusb.git
b) in MYSYS2 MYSYS shell, clone libusb repo
    Gerald@MSI-DESKTOP MYSYS ~
    $ git clone https://github.com/libusb/libusb.git 
c) cd to libusb dir
    Gerald@MSI-DESKTOP MYSYS ~
    $ cd libusb/
d) run bootstrap.sh
   Gerald@MSI-DESKTOP MYSYS ~/libusb
    $ ./bootstrap.sh
e) run configure
    Gerald@MSI-DESKTOP MYSYS ~/libusb
    $ ./configure
f) run make
    Gerald@MSI-DESKTOP MYSYS ~/libusb
    $ make -j6
g) run make install
    Gerald@MSI-DESKTOP MYSYS ~/libusb
    $ make install

7) Build libusb-compat-0.1
a) in browser, expand Build libusb-compat-0.1 > Run git clone https://github.com/libusb/libusb-compat-0.1.git
b) in MYSYS2 MYSYS shell, cd to /home/Gerald
    Gerald@MSI-DESKTOP MYSYS ~/libusb
    $ cd ..
c)in MYSYS2 MYSYS shell, clone libusb-compat0.1 repo
    Gerald@MSI-DESKTOP MYSYS ~
    $ git clone https://github.com/libusb/libusb-compat-0.1.git
d) cd to libusb-compat0.1 dir
    Gerald@MSI-DESKTOP MYSYS ~
    $ cd libusb-compat-0.1/
e) run bootstrap.sh 
    Gerald@MSI-DESKTOP MYSYS ~/libusb-compat-0.1
    $ ./bootstrap.sh
f) run configure
    Gerald@MSI-DESKTOP MYSYS ~/libusb-compat-0.1
    $ ./configure   
g) run make
    Gerald@MSI-DESKTOP MYSYS ~/libusb-compat-0.1
    $ make -j6
h) run make install
    Gerald@MSI-DESKTOP MYSYS ~/libusb-compat-0.1
    $ make install

8) Build hidapi
a) in browser, expand Build hidapi > Run git clone https://github.com/libusb/hidapi.git
b) in MYSYS2 MYSYS shell, cd to /home/Gerald
    Gerald@MSI-DESKTOP MYSYS ~
    $ cd hidapi/
c) in MYSYS2 MYSYS shell, clone hidapi repo
    Gerald@MSI-DESKTOP MYSYS ~
    $ git clone https://github.com/libusb/hidapi.git
d) cd to hidapi dir
    Gerald@MSI-DESKTOP MYSYS ~
    $ cd hidapi/
e) run bootstrap
    Gerald@MSI-DESKTOP MYSYS ~/hidapi
    $ ./bootstrap
f) run configure
    Gerald@MSI-DESKTOP MYSYS ~/hidapi
    $ ./configure
g) run make all
    Gerald@MSI-DESKTOP MYSYS ~/hidapi
    $ make all -j4
h) run make install
    Gerald@MSI-DESKTOP MYSYS ~/hidapi
    $ make install
    
9) Build AVaRICE
a) in browser, expand Build AVaRICE
b) in MYSYS2 MYSYS shell, cd to /home/Gerald
    Gerald@MSI-DESKTOP MYSYS ~/hidapi
    $ cd ..
c) clone AVaRICE
    Gerald@MSI-DESKTOP MYSYS ~
    $ git clone https://github.com/avrdudes/avarice
d) cd to avarice dir
    Gerald@MSI-DESKTOP MYSYS ~
    $ cd avarice/
e) run bootstrap
    Gerald@MSI-DESKTOP MYSYS ~/avarice
    $ ./Bootstrap
f) run configure
    Gerald@MSI-DESKTOP MYSYS ~/avarice
    $ ./configure
g) run make
    Gerald@MSI-DESKTOP MYSYS ~/avarice
    $ make -j6
h) run make install
    Gerald@MSI-DESKTOP MSYS ~/avarice
    $ make install DESTDIR=$(pwd)/avarice_installed/
i) verify installation
    Gerald@MSI-DESKTOP MSYS ~/avarice
    $ ls -R avarice_installed
