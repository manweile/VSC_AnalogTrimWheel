c) via avrdude command line for atmega32u4 via atmel-ice ISP mode, LFUSE: 0xFF, HFUSE: 0x18, EFUSE: 0xCB
avrdude -c atmelice_isp -p atmega32u4 -P usb -U lfuse:w:0xff:m -U hfuse:w:0x18:m -U efuse:w:0xcb:m 

2) openocd cli for atmel via jtag to arduino micro
openocd -f interface/cmsis-dap.cfg -c "set CHIPNAME atmega32u4" -c "source [find target/atmega32u4.cfg]"
